# 0.8.668 / vc689 体验验收

本包给「设置 → 子任务（Subagent）」加上独立的模型来源选择。默认跟随父会话实际选定的模型；也可以指定供应商和模型，从下一次运行起仅对子任务生效。不改父会话的模型选择、会话归属与存储格式。安装完成不等于手感验收通过。

## 本包变化

- **模型来源**：新增「跟随当前会话」与「指定模型」两个选项。跟随为默认，不写任何子任务专属配置。
- **指定模型**：先从有已启用模型的供应商里选供应商，再从该供应商已启用模型里选模型；选定后自动保存。子任务会使用所选供应商的接口地址、API Key、协议与模型。
- **失效回退**：指定的供应商或模型被删除、禁用或不再可用时，设置页提示「原先指定的模型已不可用，子任务会跟随当前会话」，运行链路也回退到父会话模型。
- **运行生效边界**：新的选择从下一次父任务运行起生效，不中途切换正在执行的子任务。
- **请求隔离**：换到不同供应商时清空父任务的高级请求头，避免凭据随子请求带过去；同连接则保留。子任务的采样参数按该供应商自己的设置解析。
- **下拉返回**：模型来源里的供应商、模型两个下拉打开时按返回先收起下拉，不再直接退出页面。

## 手动回归

1. 进入「设置 → 子任务」，确认默认选中「跟随当前会话」；父会话换模型后运行一个会委派子任务的任务，确认子任务跟随该模型。
2. 切到「指定模型」，依次选供应商、已启用模型；返回设置页再进入，确认选择仍在。运行任务，确认子任务使用指定端点与模型，而父会话继续用原来的模型。
3. 到「模型与生成」里禁用或删除刚指定的模型，回到子任务设置页，确认出现失效提示且子任务回退跟随当前会话。
4. 打开供应商或模型下拉后按返回，确认只收起下拉、页面不退出。
5. 顺带确认两个供应商连接不同时，子任务请求不会带上父任务的高级请求头。
