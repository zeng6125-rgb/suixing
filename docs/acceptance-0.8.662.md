# 0.8.662 / vc683 体验验收

本包把图标统一到同一套眼睛、给悬浮球加上眨眼与左右转、收紧队列按钮、修删除会话跳错、重做模型的选择层级，并让助手回复可以带图。不改阅读锚点、审批语义、会话存储格式与抽屉物理参数。安装完成不等于手感验收通过。

## 本包变化

- **图标**：方形与圆形启动图标全部重生，眼睛改成原图高光像素（左宽右窄、带倾角），位置按圆形版的基准偏移 `x=-0.050r`、`y=+0.085r`。方形保留圆角白底 + 左下绿球构图，四边圆角与原图标逐点一致。软件内抽屉头、空态、引导页 orb、助手兜底头像、关于页统一改用同一张 `brand_mark` 位图，不再用几何胶囊重画（几何版比原图大 19%~43%）。
- **悬浮球**：直径 36→42dp（触控区 44→48dp），去掉右下状态点与呼吸脉冲；空闲播眨眼、运行中播左右转眼。帧动画由 GIF 拆帧（眨眼 60→9 帧、转眼 90→23 帧，合并连续相同帧），窗口 detach 时停帧回调。
- **队列按钮**：右侧三个图标占位由 48dp 收到 32dp，图标仍 16dp，动作与无障碍名称不变。
- **会话切换**：旧正文短淡出后再发布目标会话，新正文恢复阅读位置后淡入。
- **删除会话**：删掉当前会话后走与点击会话同一条路径（无剩余会话则新建），不再出现"屏幕是空正文、抽屉却高亮另一条会话"。
- **模型**：
  - 聊天页模型切换器**只列已启用模型**（原来会把"当前模型"强行塞进分组，导致未启用模型既显示又被选中）。
  - 模型页「测试连接使用的模型」改为下拉，只列当前供应商已启用模型，且**只用于测试**，不再改写全局聊天模型。
  - 切换/删除供应商不再自动选中第一个已启用模型。
  - 助手不再指定模型；模型只有两层来源——**会话自己的选择 → 全局默认**，最近一次选择即成为新会话的默认。
  - 接口协议与供应商两个下拉：打开时按返回先收起下拉，不再直接退页并残留浮层。
- **助手发图**：回复正文里的 Markdown 图片语法 `![说明](地址)` 渲染成真图（`http(s)` 联网、`data:image/...;base64` 走本地解码）。围栏代码块里的同样写法保持原文；相对路径与未闭合语法按文字处理。

## 手动回归

1. 桌面上看方形与圆形图标是否同一张脸、四角圆润；应用内抽屉头、空聊天页、引导页、助手头像、关于页是否同一颗球。
2. 悬浮球：不在前台时确认大小、无状态点；空闲时眨眼、跑任务时左右转眼，任务结束后回到眨眼。
3. 输入框上方队列右侧三个图标是否够紧凑，且发送/编辑/删除仍能各自触发。
4. 抽屉里删掉当前会话：应落到另一条会话并显示它的正文，或干净地进入新会话；抽屉高亮与屏幕内容一致。
5. 模型页：两个下拉打开时按返回，应只收起下拉；「测试连接使用的模型」下拉只列已启用模型，测完不影响聊天模型；切换供应商不应自动选中模型。
6. 聊天页模型切换器分组里不应出现未启用模型；在一条会话里换模型后，新开会话应沿用这次选择，而旧会话保持原选择。
7. 助手编辑页不再有模型下拉；让助手回复里带 `![图](https://...)`，应显示为图片。
