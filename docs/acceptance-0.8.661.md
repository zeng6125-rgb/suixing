## 本包变化

- **会话切换**：抽屉开始关闭后旧正文用 90ms 退场，退场完成且切换意图仍有效时才发布目标会话；新正文仍在恢复阅读位置后淡入，180ms 曲线降低首帧透明度突升，不移动阅读点。正文与导航条共用同一个退场透明度，在绘制期读取；快速连续选择、关闭中断、回到已退出的会话都不会残留旧正文或错会话。
- **候选列表**：整卡从底边做 90%→100% 的轻展开与收起，文字不缩放、输入框不撑高。筛选时旧内容 60ms 退场，新内容延迟 40ms 后用 130ms 入场，高度 180ms 过渡，缩短两份不同文字同时亮着的时间。保留完整候选快照身份、从过渡内容渲染、底部锚定、退场内容留存与仅最新候选可交互。
- **队列按钮**：三个图标动作的横向占位从默认 48dp 收到 36dp，与 36dp 的队列行等高；图标仍为 16dp，发送/插入、编辑、删除回调与无障碍名称不变。

## 手动回归

1. 抽屉里往返长短会话，做快速连续选择、关闭中断、中途返回；确认没有旧正文复亮、错会话、阅读位置偏移，切换过渡比旧版连贯。
2. 输入 `/`，筛选到单项再退回，快速清空重输、同数量换成不同指令；确认候选卡从底边轻展开、无明显双影或裁边、退场旧项不可误点、输入法与焦点保持。
3. 检查输入框上方队列右侧三个图标紧凑成一组，仍能分别正确触发对应动作。
4. 顺带检查原有抽屉拖动与开收、悬浮球轻按/拖动、前后台切换，确认没有连带回归。
