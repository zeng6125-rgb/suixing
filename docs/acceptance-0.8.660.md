# 0.8.660 / vc681 体验验收

本包把斜杠指令接回正常对话链路，统一目标条与排队样式，补用户消息里的链接/路径/指令高亮，并修候选数量变化时的整块跳变。不改阅读锚点、审批语义、会话归属、存储格式与抽屉物理参数。安装完成不等于手感验收通过。

## 本包变化

- **斜杠指令**：`/goal 目标`、裸 `/goal`、`/goal clear` 及其它工具指令都作为正常消息发出，出现用户气泡、工具交互卡与模型回复，不再只有底部提示。目标先写入，模型首次请求即带新目标。
- **队列与失败**：运行中排队的指令逐个在安全边界认领。前一条失败或停止时，后面的指令留在队列，未启动的不从队列消失；被禁用或已断开的旧指令保留可撤回，不降级成普通文本。
- **编辑重发**：编辑指令后重新发送会先校验，新调用随首请求一起送出；普通"重新回答"不重复执行旧指令。
- **目标条**：与排队项统一36dp高度、14dp圆角、同底色与左右内缩，编辑/清除使用同一组操作图标。
- **候选目录**：与执行共同遵守助手禁用列表，不再展示点了会拒绝的指令。
- **用户消息高亮**：小写 http(s) 链接主色加下划线；常见 Android 绝对路径主色并复用既有路径菜单；行首有效指令词主色。原文、符号、换行、复制与修改行为不变。
- **候选增减**：卡片内部统一120ms淡出/淡入与高度过渡，边框随中间高度收放，不再出现先掉一截的透明空隙；退出中的旧项不可点，同数量不同指令也能正确替换。
- **隐私**：`ui_type`、`ui_type_into`、`clipboard_write` 的参数沿用既有脱敏策略，不重复写入用户消息、插话记录或从首条消息派生的标题；真实执行参数仍在当轮内存中。

## 手动回归

1. 发送 `/goal 完成迁移`。确认立即出现用户气泡与目标工具卡，回复内容基于新目标；再发裸 `/goal` 读回、`/goal clear` 清除。检查输入框上方目标条与排队项高度、圆角、间距一致，编辑与清除按钮可用。
2. 长任务进行中先发一条会失败的指令，紧接着发 `/goal`；确认失败后第二条仍在队列且可撤回。停止运行后同样检查后续指令未丢失。
3. 对已有 `/goal` 消息点"修改"，改成新目标后"重新发送"；确认旧回答被截断、首轮即用新目标。再试一次"只保存"，确认不发起新请求。
4. 发送带 `https://example.com/a`、`/sdcard/Download/报告.pdf`、`打开https://example.com` 的消息，检查高亮与点击行为；确认复制出来仍与输入完全一致。
5. 输入 `/`、增删候选词、同数量换成不同指令、删空后立即重输。确认候选卡整块平滑收放、无透明空隙、退场旧项不可误点、输入法与焦点保持。
6. 检查原有抽屉拖动与开收、快速切会话后的阅读位置与180ms淡入、悬浮球轻按/拖动，以及前后台切换。
