# 设置及子页的共享样式

实现入口：`ui/components/SettingsStyle.kt`、`SettingControls.kt`、`Cards.kt`。页面标题继续使用现有 PageTopBar，保留已确认的栏内位置和外观。

## 间距

| 用途 | 标准 |
|---|---|
| 页面左右留白 | 16dp |
| 普通卡片内边距 | 16dp |
| 卡片/内容区之间 | 12dp |
| 设置行上下内边距 | 各 12dp |
| 行文字与右侧控件 | 12dp |
| 同行内容的小间隔 | 4dp |
| 输入项间隔 | 8dp |
| 分组标题上下 | 12dp / 8dp |
| 页面顶部 | PageTopBar 已留空隙，内容不再叠加 |
| 页面底部 | settingsPagePadding 在滚动内容内统一避让导航栏 |

SettingRow 默认不加横向留白，卡片提供一次 16dp；需要涟漪铺满的整卡设置行把这份留白放到行内，避免相加变成 32dp。

## 字体角色

下表是标准字体档的字号/行高；全部取主题 TextStyle，随应用与系统字号缩放。

| 用途 | SettingsStyle | 主题角色 | 标准 sp |
|---|---|---|---|
| 设置行标题 | rowTitle | bodyLarge | 17 / 28 |
| 普通正文、输入框 | body / fieldText | bodyMedium | 15 / 24 |
| 说明文字 | description | bodySmall | 13 / 18 |
| 次级信息 | metadata | labelMedium | 13 / 18，中等字重 |
| 分组标题 | sectionTitle | titleSmall | 15 / 21，中等字重 |
| 卡片标题 | cardTitle | titleMedium | 18 / 25，中等字重 |
| 操作文字 | controlLabel | labelLarge | 14 / 20 |
| 紧凑徽标 | badge | labelSmall | 11 / 15 |

分组标题走 SettingSectionTitle，统一主题主色和上/下间距。输入框不再在某个页面把 bodyMedium 额外乘 15/14，避免与其它页面同类字段字号不同。

## 覆盖与实际调整

| 页面 | 已统一的内容 |
|---|---|
| 设置首页、模型、会话、外观、网络语音、数据、会话管理 | 页边距、内容分组、行/输入框文字角色与间距 |
| 工具、技能、MCP、插件及链接导入 | 页面留白、分组标题、字段角色；工具卡从 6dp 卡间距、7dp 纵向内距改为共享 12dp/16dp |
| 画像、关于 | 说明与输入角色；画像/关于的卡片标题统一 18sp |
| 助手列表、助手编辑 | 去掉列表额外 10dp 纵向空白；编辑页使用共享边距和底部留白 |
| 用量、性能 | 统一分组标题；性能页消除叠加的 12dp 标题上边距；用量改内容内避让导航栏 |
| 记忆、能力、文件 | 使用相同间距和角色；记忆/能力的底部留白归滚动内容，能力卡恢复共享 16dp 内距 |

统计数字保留窄屏时的同字号适配，头像/图标保留自身尺寸，紧凑徽标保留 badge 角色；不同语义不会强行使用一种字号。对话框继续复用现有 SuixingDialog，主操作按钮继续使用 Material 控件。

以上是源码规则与编译核验；浅/深色、特大字体、窄屏的实际排版与滚动手感尚未逐页真机验收。
